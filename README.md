# NAMBikkai Shield

**Pause. Verify. Protect. Report.**

NAMBikkai Shield is a multilingual digital-safety awareness prototype designed to help people recognise common cyber-scam warning signs and choose safer next steps.

## Features

- Rule-based suspicious-message warning analysis
- English, Malayalam, Hindi and Tamil language selection
- Calm Help Mode for simpler guidance
- Interactive Scam-Pressure Simulator
- Evidence-organising checklist
- Guidance for official cybercrime reporting in India

## Technology Stack

- Python
- Streamlit

## Run Locally

1. Install Python.
2. Open a terminal in this project folder.
3. Install the dependencies:

   `python -m pip install -r requirements.txt`

4. Start the application:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Important Limitations

This prototype uses rule-based warning indicators. Its score is not a probability or proof of fraud. A low score does not establish that a message is safe. Users should verify unexpected requests independently.

Do not enter real OTPs, passwords, PINs or bank details into the application.
